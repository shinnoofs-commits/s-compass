# **App Name**: Inhouse Connect

## Core Features:

- User Registration: User registration with name, department (from a fixed list), and optional icon image upload.
- Categorized Posts: Categorized posting using a fixed set of categories (Product Info, Orders, Operations, iPad, Announcements, Other).
- Push Notifications: Push notifications to notify users of new posts.
- Post Listing: Display of posts in chronological order, with starred posts pinned to the top. Display title, category, author, department, date, and star icon.
- Post Details: Full post display including text formatting, attached files, images, author info, read status, view count, and comment/reaction features.
- Post Editor: Post creation with required title and category, rich text editor for the body (including image insertion), attachments, star/pin options, draft saving, and scheduled posting.
- AI Post Refinement: AI-powered tool to refactor content from bullet points into detailed and easily understandable paragraphs

## Style Guidelines:

- Primary color: Turquoise (#40E0D0) to evoke calmness and reliability.
- Background color: Mint Gray (#D8E2DC), a desaturated, light tint of turquoise.
- Accent color: Serenity Blue (#93B5C6) to complement the primary and add depth.
- Headline font: 'Poppins' (sans-serif) for a modern, precise feel.
- Body font: 'PT Sans' (sans-serif) to provide a modern look with some warmth.
- Rounded, soft icons that contribute to the gentle, approachable interface.
- Use rounded UI elements, like buttons and cards, to enhance the soft and approachable feel.
