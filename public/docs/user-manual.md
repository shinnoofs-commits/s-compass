
# 社内連絡ツール - 操作マニュアル

このマニュアルは、社内連絡ツールの基本的な使い方から管理者向けの高度な機能までを解説します。

## 1. 基本的な使い方

### 1.1. ログインする

1.  管理者から共有されたURLにアクセスします。
2.  招待メールの指示に従って登録した「メールアドレス」と「パスワード」を入力し、「ログイン」ボタンをクリックします。

### 1.2. 投稿を作成する

1.  画面右下の「＋」ボタン、またはサイドバーの「新規投稿」をクリックします。
2.  **タイトル**と**本文**を入力します。
3.  **カテゴリ**を選択します。
4.  **AIで清書**: 箇条書きやメモをAIが綺麗な文章に整形します。本文入力後、ボタンを押してください。
5.  **投稿する**: すぐに全体へ公開します。
6.  **下書き保存**: 後で編集するために、下書きとして保存します。下書きはサイドバーの「下書き・予約」から確認できます。

### 1.3. 投稿を探す・読む

*   **ホーム画面**: 最新の投稿が一覧で表示されます。
*   **検索**: 画面上部の検索ボックスにキーワードを入力して、投稿を検索できます。
*   **絞り込み**: カテゴリ、投稿者の部署、投稿者名で表示する投稿を絞り込めます。

### 1.4. プロフィールを編集する

1.  サイドバー右下の自分のアイコンをクリックし、「プロフィール」を選択します。
2.  「編集する」ボタンを押し、氏名、部署、アイコン画像を変更できます。
3.  「保存する」をクリックして変更を確定します。

---

## 2. 管理者向け機能

管理者権限を持つユーザーは、サイドバーに「管理者メニュー」が表示され、以下の機能が利用できます。

### 2.1. ダッシュボード

各種管理機能への入り口です。ここから全ての管理操作を開始します。

### 2.2. 投稿管理

*   全ユーザーの投稿を一覧で確認し、必要に応じて内容を編集したり、不適切な投稿を削除したりできます。

### 2.3. ユーザー管理

1.  **新規ユーザー作成**:
    *   「新規ユーザー作成」ボタンを押すと、登録用の招待リンクが生成されます。
    *   このリンクを招待したい方に送付してください。リンクは10分間有効で、一度しか使用できません。
2.  **ユーザー情報の編集・削除**:
    *   ユーザー一覧から、各ユーザーの氏名・部署・役割などを編集できます。
    *   不要なアカウントはここから削除できます。
3.  **パスワードリセット**:
    *   パスワードを忘れたユーザーのために、管理者がリセットメールの送信を代行できます。

### 2.4. 対象範囲を指定して投稿する

管理者は投稿作成時に、その情報を閲覧できる範囲を限定できます。

1.  投稿作成画面で「対象範囲設定」エリアを開きます。
2.  「全社」または「部署指定」を選択します。
3.  「部署指定」を選んだ場合、さらに対象の部署と、その部署の「全員」か「特定の個人」かを選択できます。

### 2.5. データのエクスポート

*   全ユーザーの一覧情報や、全投稿データをCSVファイルとしてダウンロードできます。データのバックアップや分析に活用できます。

### 2.6. システムの稼働状態管理

*   外部からの不正アクセスなど、緊急事態が発生した際にシステムを「緊急停止」できます。
*   停止中は、管理者以外の全ユーザーはメンテナンス画面が表示され、アプリを利用できなくなります。
*   管理者はこの画面からいつでもシステムを「再開」できます。
