
# 社内連絡ツール - システム仕様書

## 1. 概要

### 1.1. 本システムについて

本システムは、多店舗展開を行う企業様向けに設計された、リアルタイム情報共有を促進するための社内連絡・掲示板ツールです。PCおよびスマートフォンからアクセス可能で、通達事項の確実な伝達、円滑なコミュニケーション、業務効率の向上を実現します。

### 1.2. 目的

*   **情報伝達の迅速化と確実化**: 本部から各店舗、店舗間での情報共有を円滑にし、伝達漏れや認識の齟齬を防ぎます。
*   **コミュニケーションの活性化**: 部署や役職の垣根を越えたコミュニケーションを促進し、組織の一体感を醸成します。
*   **業務ナレッジの蓄積と活用**: 業務連絡やQ&Aをデジタルデータとして蓄積し、検索可能なナレッジベースとして活用します。

## 2. 機能一覧

### 2.1. ユーザー向け機能

| 機能名 | 概要 |
| :--- | :--- |
| **ユーザー認証** | メールアドレスとパスワードによる安全なログイン。 |
| **投稿作成・編集** | Markdown形式に対応したリッチな投稿を作成・編集可能。 |
| **AIによる本文清書** | 箇条書きやメモを、AIが自然で丁寧な文章に自動で清書します。 |
| **投稿閲覧** | タイムライン形式で投稿を閲覧。キーワード、カテゴリ、部署等での絞り込みや並び替えが可能。 |
| **コメント機能** | 各投稿に対してコメントを投稿し、ディスカッションを行えます。 |
| **いいね機能** | 投稿に対するポジティブな反応をワンクリックで伝えられます。 |
| **下書き・予約投稿** | 作成途中の投稿を下書きとして保存したり、未来の日時を指定して予約投稿したりできます。 |
| **プロフィール編集** | 氏名、部署、アイコン画像などをユーザー自身で変更できます。 |

### 2.2. 管理者向け機能

| 機能名 | 概要 |
| :--- | :--- |
| **管理者ダッシュボード** | 各種管理機能へアクセスするためのポータル画面。 |
| **全投稿管理** | 全ユーザーの投稿（下書き含む）を横断的に閲覧、編集、削除できます。 |
| **ユーザー管理** | 全ユーザーの一覧、情報編集、役割変更（管理者/店長/ユーザー）、パスワードリセット、アカウント削除。 |
| **新規ユーザー招待** | セキュリティを担保した招待リンクを発行し、新規ユーザーを安全に登録させます。 |
| **対象範囲指定投稿** | 投稿の閲覧権限を「全社」「特定部署」「部署内の特定個人」に限定できます。 |
| **データエクスポート** | ユーザー情報や投稿データをCSV形式で一括ダウンロードできます。 |
| **稼働状態管理** | 緊急時にシステム全体をメンテナンスモードに切り替え、一般ユーザーのアクセスを制限できます。 |

### 2.3. バックエンド自動化機能

| 機能名 | 概要 |
| :--- | :--- |
| **投稿数上限管理** | 1日の総投稿数が設定値（例: 100件）に達した場合、自動で投稿機能を一時停止し、サーバー負荷を抑制します。 |
| **日次リセット** | 毎日午前5時に、投稿カウンターのリセットと投稿機能の自動再開を行います。 |

## 3. 技術仕様

本システムは、モダンなWeb技術とクラウドサービスを全面的に採用し、高いスケーラビリティ、セキュリティ、保守性を実現しています。

| 領域 | 使用技術/サービス | 目的 |
| :--- | :--- | :--- |
| **フロントエンド** | Next.js (React), TypeScript | 高速な表示速度とSEO、品質の高いコードを実現。 |
| **UIコンポーネント** | ShadCN UI, Tailwind CSS | モダンで美しいデザインと、高いカスタマイズ性。 |
| **バックエンド** | Firebase (Cloud Functions) | サーバーレスアーキテクチャによる高い保守性と拡張性。 |
| **データベース** | Firebase (Firestore) | リアルタイム性に優れたNoSQLデータベース。柔軟なデータ構造に対応。 |
| **認証** | Firebase Authentication | パスワード管理、セキュアなログイン機能を提供。 |
| **AI機能** | Google AI (Gemini) | Googleの最新AIモデルを活用し、高度な文章生成機能を実現。 |
| **インフラ** | Google Cloud Platform | Googleの堅牢なインフラ上でシステム全体を稼働。 |

---

## 4. セキュリティ

*   **通信の暗号化**: 全ての通信はSSL/TLSによって暗号化されています。
*   **認証**: Firebase Authenticationにより、業界標準の安全な認証基盤を提供します。
*   **アクセス制御**: Firestoreのセキュリティルールにより、ユーザーの役割や権限に基づいた厳格なデータアクセス制御をサーバーサイドで強制します。
*   **サーバーサイドロジック**: 投稿数制限などの重要なロジックは全てCloud Functions上で実行され、クライアントからの不正な操作を防ぎます。
